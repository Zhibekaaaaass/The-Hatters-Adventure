# The Hatter’s Adventure

## About the Game
**The Hatter’s Adventure** is a 2D action-platformer developed in Unity. The player explores fantasy environments, jumps over obstacles, collects items, shoots enemies, and fights a boss.

The main goal is to complete all three levels and overcome the challenges.

## Game Information
- **Title:** The Hatter’s Adventure
- **Genre:** 2D Action-Platformer
- **Engine:** Unity
- **Platform:** Android / iOS
- **Orientation:** Landscape
- **Game Type:** Single-player

## Main Features
- 2D player movement and jumping
- Mobile on-screen controls
- Shooting mechanics
- Enemies and environmental hazards
- Player health system
- Three playable levels
- Boss fight in Level 3
- Main Menu
- HUD with gameplay information
- Pause Menu with Resume, Restart, and Exit options

## Controls
The game uses on-screen mobile controls:

- **Joystick:** Move the player
- **Jump Button:** Jump
- **Fire Button:** Shoot
- **Pause Button:** Open the Pause Menu

## Levels
- **Level 1:** Introduction to the basic gameplay mechanics.
- **Level 2:** More challenges, enemies, and obstacles.
- **Level 3:** Final level with a boss fight.

## Development
This project is being developed as part of the Game Development Fundamentals course.

The project focuses on 2D gameplay, mobile controls, user interface design, and level development.
